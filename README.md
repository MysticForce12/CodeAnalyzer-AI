An AI-powered code review platform built with the MERN stack.
Users can authenticate, submit source code, receive AI-generated feedback, manage previous analyses, and export reports.

>  This project is currently under active development.



## Features

### Completed

- User Authentication
  - Register
  - Login
  - Logout
  - JWT Authentication
  - HTTP-only Cookies
- Protected Backend APIs
- User Profile Management
- React Authentication Context
- Responsive Login & Register Pages

### In Progress

- Protected Routes
- Dashboard
- AI Code Analysis
- Analysis History
- PDF Export
- UI Improvements

### Planned

- Monaco Code Editor
- Gemini AI Integration
- Analysis History
- Code Review Dashboard
- Framer Motion Animations
- Better Error Handling
- Toast Notifications

## Getting Started

### Clone the repository

```bash
git clone https://github.com/MysticForce12/CodeAnalyzer-AI.git
```

### Install dependencies

```bash
# Frontend
cd client
npm install

# Backend
cd ../server
npm install
```

### Run the project

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
